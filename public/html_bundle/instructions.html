১. Google Docs (docs.google.com) এ যুক্ত করার পদ্ধতি

  1. আপনার Google Docs ডকুমেন্ট খুলুন।
  2. যেখানে লিঙ্ক যুক্ত করতে চান সেখানে "Natok Explain Automation App" বা পছন্দের টেক্সট লিখুন।
  3. টেক্সটটি সিলেক্ট করে কীবোর্ডের Ctrl + K (ম্যাক-এ Cmd + K) চাপুন।
  4. লিংক বক্সে নিচের ইউআরএলটি পেস্ট করে Apply চাপুন:
    https://rubel-vai-natok-explain-automotion-v3-7.ai.studio/
  5. এছাড়াও চাইলে Google Docs এর "Smart Canvas / Smart Chip" ব্যবহার করে সহজে প্রিভিউ কার্ড তৈরি করতে পারেন।

২. Google Drive-এ এই জিপ ফাইল আপলোড করার পদ্ধতি

  1. Google Drive এ যান।
  2. + New বাটনে ক্লিক করে File upload বেছে নিন।
  3. আপনার natok_explain_html.zip ফাইলটি আপলোড করুন।
  4. ফাইলের ওপর রাইট ক্লিক করে Share > Anyone with the link নির্বাচন করে লিঙ্কটি আপনার Google Docs-এ যুক্ত করতে পারেন।

৩. সরাসরি কম্পিউটারে বা মোবাইলে ব্রাউজারে চালানোর নিয়ম
